# 📖 Módulo 14: Proyectos Prácticos Integradores de Código a Mano

En este módulo ensamblarás todos los conocimientos de JavaScript mediante 4 proyectos completos ejecutables para afianzar la lógica de programación y la interacción con datos y estado.

---

## 🛠️ Proyectos Prácticos

1. [01_proyecto_calculadora.js](./01_proyecto_calculadora.js):
   - Motor de calculadora con operaciones aritméticas, redondeo con `Math`, validación defensiva y control de historial.

2. [02_proyecto_kanban_todo.js](./02_proyecto_kanban_todo.js):
   - Gestor de tareas To-Do / Kanban completo: agregar, cambiar estado (*pendiente*, *en progreso*, *completada*), filtrado y serialización con `JSON`.

3. [03_proyecto_dashboard_clima_fetch.js](./03_proyecto_dashboard_clima_fetch.js):
   - Motor asíncrono con `async/await` que consulta y transforma datos de meteorología, gestiona tiempos de espera y respuestas de red con control de errores.

4. [04_proyecto_validador_regex.js](./04_proyecto_validador_regex.js):
   - Sistema de validación de registro de usuarios en tiempo real con expresiones regulares (Email estricto, contraseña segura con mayúsculas/números, teléfonos internacionales).
