# 📖 Módulo 15: Proyectos Prácticos Integradores de Node.js

Cuatro proyectos prácticos de arquitectura backend para consolidar tus habilidades con Node.js puro.

---

## 🛠️ Proyectos Prácticos

1. [01_proyecto_servidor_estatico.js](./01_proyecto_servidor_estatico.js):
   - Servidor HTTP nativo con resolución de MIME types y lectura con streams.

2. [02_proyecto_api_rest_nativa.js](./02_proyecto_api_rest_nativa.js):
   - Enrutador HTTP nativo para peticiones GET y POST con parseo del cuerpo de la solicitud.

3. [03_proyecto_cli_backup.js](./03_proyecto_cli_backup.js):
   - Herramienta de consola para respaldar archivos comprimiéndolos en Gzip con streams y pipeline.

4. [04_proyecto_monitor_sistema.js](./04_proyecto_monitor_sistema.js):
   - Monitor de recursos de hardware en consola usando métricas del módulo `os` y `process`.
