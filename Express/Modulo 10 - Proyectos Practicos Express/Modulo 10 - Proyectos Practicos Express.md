# Módulo 10: Proyectos Prácticos Integradores Express

Este módulo final consolida todo lo aprendido en proyectos listos para codear a mano.

---

## Proyecto 1: API RESTful CRUD de Tareas
Crea un sistema completo de rutas con verbos HTTP, almacenamiento en memoria, códigos de estado HTTP y validación de datos.

## Proyecto 2: Servidor de Archivos y Descargas
Sirve archivos estáticos, implementa endpoints para descargar documentos con nombres personalizados y valida tipos de archivos.

## Proyecto 3: Middleware de Autenticación y Control de Acceso
Implementa protección de rutas mediante encabezados de autorización Bearer Token y roles de usuario.
